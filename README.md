# ClinicaApp

Aplicacion de consola en Java para gestionar una clinica medica.
Permite administrar pacientes, medicos y citas, con persistencia en base de datos MariaDB.

## Funcionalidades

- Gestion de pacientes y medicos (alta, busqueda, listado)
- Gestion de citas (reservar, cancelar, ver historial)
- Generacion de tickets de cita en fichero de texto
- Menu diferenciado para Administrador y Paciente

## Configuracion

Conectada con su base de datos (ClinicaApp.db)
## Tecnologias

Java JDK 24 | MariaDB | JDBC | Maven | JUnit 5
